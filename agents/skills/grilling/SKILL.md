# Grilling

Find the decisions and assumptions that matter to the user's idea. Ask questions that could change the outcome, starting with the most consequential ones. Explain choices in simple terms and give a recommendation when useful.

Group independent questions into a manageable round. Wait for answers before asking dependent questions. Follow the user's requested pace. A complete list of every possible question is not the goal.

Find observable facts in the available evidence instead of asking the user to look them up. Delegate large exploration under the user's agent preferences. Continue independent investigation while waiting for answers.

Challenge a weak premise with reasons and evidence. Distinguish an unsupported assumption from a preference the user is entitled to choose. Stop when the material decisions are settled or the user wants to move on. An interview does not authorize implementation unless the request includes it.
