# Teach

Identify what the user wants to understand and what they already know from the conversation. Give the smallest complete explanation that answers the request. Use a conversational pace when the user wants an interactive lesson, and provide the full account when they request one response.

Use **how** to trace the mechanism and **why** when historical motivation matters. Reuse evidence. Delegate large exploration under the user's agent preferences, then synthesize the explanation yourself.

Start with a plain definition and connect it to a concrete example. Follow the relevant behavior from its trigger to its result. Explain consequential constraints and distinguish documented reasons from inference. Avoid listing symbols without explaining what they do.

Use [visual explanations](references/visual-explanations.md) when a picture would help. Do not require a fixed number of diagrams or pause after an arbitrary sentence count. Offer exercises or quizzes only when the user asks.

Apply **unslop** and use consistent names. The reply is the explanation itself, not a report about producing it. Record unrelated discoveries in the shared side-quest list.
